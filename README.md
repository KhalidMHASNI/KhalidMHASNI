# Khalid Mhasni

Deep learning and computer vision, Moulay Ismaïl University (Meknes, Morocco).

## Selected work

- [AI-generated face detection](https://github.com/KhalidMHASNI/Using-Advanced-Algorithms-in-DL-to-Identify-AI-Generated-Faces): texture-based detector built on the PatchCraft architecture, trained on FFHQ and StyleGAN2 faces (82.62% accuracy), with a Flask web demo.
- [Real-time parking space availability](https://github.com/KhalidMHASNI/Real-time-Prediction-of-Parking-Spaces-Availability): YOLOv8 transfer learning on a custom parking-lot dataset.
- [NER on MIT Restaurants](https://github.com/KhalidMHASNI/NER-presentation-MITRestaurants-NLP): token-level entity recognition for restaurant search queries, using TF-IDF features and scikit-learn classifiers.
- [Chatbot with Spring AI](https://github.com/KhalidMHASNI/Ai-chatbot-using-Spring-AI): streaming chat with conversation memory.
- [Obstacle-avoiding robot](https://github.com/KhalidMHASNI/ObstacleAvoidingRobot-Arduino): autonomous Arduino robot with obstacle detection.

## Stack

Python · Java (Spring Boot) · scikit-learn · YOLOv8 · Flask · Django · Arduino (C++)
